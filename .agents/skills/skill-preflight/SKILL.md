# Skill preflight

This skill turns the root `AGENTS.md` first-connection law into a repeatable procedure.

## Entry invariant

```text
know this is Omniphony
→ read current root authority
→ discover current skill surface
→ identify exact obligation
→ select applicable skills
→ read selected current skill bodies
→ act through their combined constraints
```

Do not absorb every skill body or the whole repository first.

## Mandatory preflight

1. Read current `AGENTS.md`.
2. Read the smallest relevant `README.md` identity/routing surface.
3. Enumerate current `.agents/skills/*/SKILL.md`.
4. Compare each skill's name and description with the exact obligation.
5. Select process/control skills before domain/execution skills.
6. Read every selected current skill body before taking the action it governs.
7. Preserve the selected skill set only in ephemeral task state.
8. Refresh awareness when `AGENTS.md`, `README.md`, `.agents/skills/`, or the obligation changes materially.

A skill is applicable when omitting it could change decomposition, evidence collection, falsification, mutation, concurrency handling, publication, re-entry, or capability-debt handling.

Current bytes outrank remembered procedure.

## Typical process routing

```text
repository mutation
→ repo-change

GitHub connector mutation
→ github-workspace + repo-change

hot/concurrent main
→ github-workspace + github-workspace-liveness + repo-change

blocked executable/runtime obligation
→ codex-handoff
```

The live skill inventory is authoritative.

## Self-awareness capsule

Before deep execution, know:

```text
system = Omniphony
authority = AGENTS.md
identity = README.md
current-head = exact repository state when repository work is in scope
obligation = exact task
canonical-owner = current owner or unresolved
selected-skills = applicable current skill paths
protected-constraints = user + repository + task invariants
verification-boundary = what can actually execute here
```

Resolve only missing fields that can change the next decision.

A skipped applicable skill is a routing defect.
